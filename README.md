# 麗京特別市 城市圖鑑（原生版）

《環》麗京特別市（舊平潭）的城市參考工具，給《城市天際線 2》重建用。
以 Rust + wgpu 直接驅動顯示卡（Windows 用 DirectX 12／Vulkan），不經過瀏覽器。

## 執行

解壓縮後雙擊 `lijing.exe`。`data` 資料夾必須和 exe 放在同一層。

## 操作

| 動作 | 方式 |
|---|---|
| 平移 | 左鍵拖曳；WASD／方向鍵 |
| 旋轉、傾斜 | 右鍵或中鍵拖曳；Shift／Ctrl／Alt＋左鍵拖曳；Q／E 旋轉、R／F 傾斜 |
| 左鍵改成轉視角 | 底部「左鍵：平移」按鈕或 T 鍵（上下拖曳傾斜、左右拖曳旋轉） |
| 縮放 | 滾輪（往游標位置）；＋／－ |
| 模式 | 6 總圖、1 平面、2 立體、3 等高線、4 運輸、5 CS2 規劃；M 量測（右鍵刪除上一點、Shift＋右鍵全部清除）；Esc 取消 |

- 時間軸：以「日」為單位，2014-01-01（戰前，Landsat 衛星影像判讀）→ 2015 接收 → 2016–2025 麗京建設。
  每棟建物有開工日、竣工日與拆除日；施工中會由鷹架與防塵網逐層長高。播放速度可選每秒 1 天／週／月／季／年。
- 總體規劃（v0.10）：全島單一棋盤路網（方位取平潭真實主幹道 63°），約 1 km 幹道超級街廓，每個超級街廓一座鄰里公園與一所學校；先拆遷、再鋪路、通車後才蓋房，每棟建物都臨接已連通主路網的道路（CS2 規則）。無法開發的山丘規劃為山林公園，戰前密集聚落保留為老街區。
- 金井港區（西岸筆直海岸）：貨櫃碼頭、岸橋、堆場、倉庫、客滾輪渡；後方為西岸港灣產業區。
- 公共運輸（v0.11）：首爾級密度、東京式直通。12 條捷運約 240 km（每線 12–30 km、穿越市心、不繞回、不共用走廊），車站 800 m 內涵蓋約 91% 的人口與就業（加上公車約 98%）；M5 離島輕軌約 55 km 從外圍轉乘站沿幹道出海；幹線公車（BRT）走每條幹道、接駁公車從捷運站繞行社區。路線分為捷運／輕軌／高鐵／幹線公車／接駁公車五類，樣式不同，點選切換開關。
- 立體層級 -2～+2：快速道路與交流道為高架（+1，交叉處 +2），匝道有坡度與橋墩，沿線與交流道範圍不蓋房；捷運在市心為地下（-1，交叉處 -2）、外圍為高架（+1，跨越高架道路處 +2）。
- 西岸港區為港口＋倉庫＋巨型住宅＋摩天樓＋商店街的混雜區（Cyberpunk 2077 風格），夜間全城商住建築有霓虹招牌。
- 右側資訊面板可用左緣箭頭收合／展開。
- CS2 分區（v0.12）：每個街廓沿街依道路等級與區位劃分 CS2 分區（低／中／高密度住宅、排屋、商住混合、低租金、低／高密度商業、低／高密度辦公、工業），地塊以 8 m 格、最深 6 格；服務設施（小學、中學、診所、警察局、消防隊、醫院）依超級街廓配置。底部「CS2 分區圖」依分區上色，滑鼠停在建物上顯示分區與地塊格數。
- 港區與市區之間：港口聯外道路、貨櫃集散站、物流園區（倉庫＋貨櫃堆場）。全城高密度（Cyberpunk 風、仍在 CS2 可建造範圍），商業建築有霓虹招牌與屋頂看板，住宅屋頂有水塔與冷氣。
- 地表也逐日變化：道路、公園、都市地坪、填海造地都在動工／通車當天才出現，不會提前出現未來的疊圖。
- 「分區邊界」：底部按鈕或右側面板勾選；點右側某個分區只顯示該分區的邊界。「特區範圍」顯示海壇島與周邊島嶼海域的特區外框。
- 地標有基地範圍（靠近或點選時以虛線標出），基地內不留道路與一般建物；北站、中央站沿高鐵軌道配置，含月台、站前廣場與公車轉運站。
- 捷運沿主要道路選線，只在轉彎處與公園切過街廓。
- 建物樣式庫：各類建物有多種屋頂（雙斜、四坡、單斜、鋸齒、筒拱）、退縮、裙樓、冠頂與立面、配色，依位置隨機選擇。
- 軌道路線預設隱藏，在右側面板點選路線開啟；運輸模式顯示全部。
- 地標與車站可開「內部剖面」，可展開樓層或只看單層。
- CS2 模式可直接把可建造範圍的 16-bit 高度圖存成檔案。
- 底部「解析度」：預設自動，FPS 低於 40 時會自動降低繪製解析度。

## 自動更新

程式啟動時會查詢 GitHub Releases 的最新版本，有新版本時畫面上方會出現提示，
按「下載並更新」→「立即重新啟動」即可。設定檔：`data/update.json`

```json
{ "repo": "擁有者/儲存庫", "asset": "lijing-windows.zip" }
```

## 發佈新版本（維護者）

1. 修改 `Cargo.toml` 的 `version`。
2. 推送標籤：`git tag v0.7.1 && git push origin v0.7.1`。
3. GitHub Actions（`.github/workflows/release.yml`）會在 Windows 上編譯並把 `lijing-windows.zip` 發佈到 Releases，
   使用者的程式下次啟動就會看到更新提示。

## 資料來源

- 地形：AWS Terrain Tiles（約 17 m），將軍山系依聖經抬升。
- 戰前（2014–15）道路與建物：Overture Maps（OpenStreetMap 道路、East Asian Building Footprints 建物）
  以 Landsat 8（2014–15 與 2020–21 同季節影像）判讀當時是否已存在。
- 麗京 2016–2025：以真實路網為骨架、在空地長出的規劃街廓與建物（程序生成）。
